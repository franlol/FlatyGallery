# Flaty Gallery

Every [LibFlatyUI-1.0](https://github.com/franlol/LibFlatyUI-1.0) component in
every state, in one window. Type `/flaty` in game.

Use it to see how a component looks and behaves before using it, and to check
changes to the lib. Nothing is saved; the status line shows the last value
you changed.

## Pages

- **Buttons**: styles, two-step confirm, dialogs, icon buttons
- **Toggles**: check boxes, switches, check groups
- **Values**: sliders, segmented choices, dropdowns
- **Text**: inputs, search box, code box, notes
- **Colors**: color swatches
- **Lists**: every kind of list
- **Cards**: folding cards, headings, separators, header buttons
- **Sections**: page sections and cards that span columns
- **Tabs and split**: a list on the left, tabbed details on the right

The header buttons grey out every control (**Grey all**) and switch the lib's
own texts to Spanish (**Español**).

## Install

Needs LibFlatyUI-1.0 installed as its own addon. Copy this folder to
`Interface/AddOns/FlatyGallery`.
